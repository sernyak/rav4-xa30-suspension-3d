# Toyota RAV4 (XA30, 2011) — ходова частина · інтерактивна 3D-модель

**Онлайн:** https://sernyak.github.io/rav4-xa30-suspension-3d/

Або локально: відкрийте **`index.html`** у браузері (Chrome / Safari / Edge / Firefox) — подвійним кліком.
Інтернет не потрібен: Three.js лежить у `lib/`.

## Що всередині
- **152 окремі деталі**, кожну можна вибрати кліком і прочитати: що це, що робить, з чим взаємодіє, ознаки зносу.
- **Передня підвіска McPherson**: амортизатор, пружина, відбійник і пильовик, верхня опора з опорним підшипником,
  поворотний кулак, нижній важіль із двома сайлентблоками (один — гідравлічний), кульова опора, стабілізатор із втулками
  та стійками, підрамник, рульова рейка з пильовиками, внутрішні тяги й наконечники, проміжний вал, колонка EPS і кермо.
- **Задня підвіска**: верхній + два нижні важелі + поздовжній (8 сайлентблоків окремо), окремі пружина й амортизатор
  з опорою, стабілізатор, підрамник, кронштейни кузова.
- **Привід AWD**: передні й задні ШРУСи (зовнішні, внутрішні, півосі, пильовики), карданний вал із проміжною опорою, задній редуктор.
- **Гальма**: вентильовані передні й суцільні задні диски, плаваючі суппорти, скоби, поршні, колодки, напрямні пальці,
  шланги, датчики ABS, колодки й трос стоянкового гальма (барабан у «шапці» диска).
- Колеса: диски 17″, шини 225/65 R17, гайки.

## Керування
| Дія | Як |
|---|---|
| Обертати / зсув / масштаб | ЛКМ / ПКМ (Shift+ЛКМ) / колесо миші |
| Опис деталі | клік по деталі або в списку ліворуч |
| Наблизити | подвійний клік; кнопки ракурсів зверху |
| Зняти вибір | Esc |

Вкладки ліворуч: **Деталі** (дерево, пошук, «очко» — сховати деталь) · **Рух** · **Вигляд** · **Довідка**.

## Рух підвіски — справжня кінематика
Положення кулака кожного колеса **розраховується** (метод Ньютона) з довжин важелів і тяг, а не анімується «на око».
Тому під час ходу колеса змінюються розвал, сходження, колія; повертаються кулаки при русі рейки;
стискаються пружини, вигинаються шланги, закручується стабілізатор. Таблиця кутів у вкладці «Рух» — це результат того розрахунку.

## Вкладка «Вигляд»
- **Розбирання (explode)** — розсуває деталі в порядку складання.
- Фільтри: окрема система (підвіска / гальма / кермо / привід / колесо), передня чи задня вісь, сховати колеса й кузов.
- Кольори: **«Акценти»** (типово — пружини сині, амортизатори жовті, важелі бірюзові, сайлентблоки й гумові опори помаранчеві, шарніри фіолетові, стабілізатори лаймові, суппорти червоні; клік по легенді підсвічує групу), **«Реалістичні»** і **«За системами»**.
- Приглушення решти деталей при виборі однієї.
- **Розмір інтерфейсу**: на великих екранах (4K/5K) панелі збільшуються автоматично; вручну — «Вигляд → Розмір інтерфейсу» (100–250%), вибір запам'ятовується. Окремо працює звичайний зум браузера (Cmd/Ctrl + 0 — скинути).

## Важливо знати
Це **навчальна схематична модель**, намальована з нуля процедурно: компоновка відповідає RAV4 XA30 (передня McPherson,
задня на подвійних важелях, окремі пружина й амортизатор, повний привід), але форми, розміри й точне розташування кріплень
узагальнені, а не зняті з креслень Toyota. Деякі деталі (тип сайлентблоків, ексцентрики, схема муфти AWD) можуть відрізнятись
у вашій комплектації. Для моментів затягування, розмірів і каталожних номерів користуйтесь сервісним мануалом і Toyota EPC.

## Структура
`index.html` — інтерфейс · `js/spec.js` — опорні точки підвіски · `js/kin.js` — кінематика ·
`js/geo.js`, `js/mats.js` — геометрія й матеріали · `js/front*.js`, `js/rear*.js`, `js/wheelend.js`, `js/cv.js`, `js/body.js` — деталі ·
`js/info.js`, `js/help.js` — тексти · `js/app.js` — UI.
Параметри в адресі для посилань: `#sel=f_arm`, `#ex=0.8`, `#fl=0.05&steer=0.5`, `#cm=real|accent|system`, `#sys=brake`.

## Ліцензії
Three.js та OrbitControls (MIT) лежать у `lib/` без змін. Решта коду — оригінальна, написана з нуля.
